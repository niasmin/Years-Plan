# คำถามถึง สสจ.เชียงใหม่ — ประเภทคลินิกหน้า รพ. (D2)

**ปัญหา:** ถ้ายื่นเป็นคลินิกเฉพาะทางระบบประสาท ผู้ดำเนินการต้องมีวุฒิบัตร/หนังสืออนุมัติสาขานั้น แต่ผู้ดำเนินการที่วางไว้ นพ.รังสรรค์ วิฑูรย์ (ว 8541) เป็นอายุรแพทย์ และคลินิกนี้มีทั้งแพทย์และกายภาพบำบัด จึงต้องถามว่ายื่นเป็นประเภทอะไร

## ข้อมูลที่ต้องเล่าให้เจ้าหน้าที่ฟังก่อนถาม

- ผู้รับอนุญาต: บริษัท ซีเอ็มเอ็นเอช 2012 จำกัด (นิติบุคคล) · ใบอนุญาตใหม่ ไม่ใช่ย้ายคลินิกหมอต้น
- ที่ตั้ง: อาคารสำนักงานหลังใหม่ด้านหน้าโรงพยาบาลที่กำลังก่อสร้าง (ที่ดินเดียวกัน) ผัง 20×11 ม.
- บริการ: ตรวจรักษาโดยแพทย์ + กายภาพบำบัด · แพทย์ 1 · RN 1 · PN 1 · PT 2 · PTA 1
- ผู้ดำเนินการ: นพ.รังสรรค์ (อายุรกรรม) ไม่ได้ทำงานที่อื่น · นักกายภาพ: นายโยธิน โพธาศักดิ์ (ก.8788)
- ระยะเวลา: เปิด ม.ค. 70 ถึง ต.ค. 70 แล้วย้ายบริการเข้า OPD ของโรงพยาบาล (คำขอ ส.พ. ยื่นแล้ว 28 ต.ค. 69)

## คำถาม

1. คลินิกที่มีทั้งแพทย์และกายภาพบำบัด ต้องยื่นเป็น **สหคลินิก** หรือยื่นเป็นคลินิกเวชกรรมที่มีนักกายภาพเป็นผู้ประกอบวิชาชีพได้
2. ถ้าต้องการใช้ชื่อหรือสื่อสารว่าเป็นคลินิก "ระบบประสาทและสมอง" ต้องยื่นเป็นคลินิกเฉพาะทางหรือไม่ หรือยื่นเป็นคลินิกเวชกรรมทั่วไปแล้วใช้ชื่อได้แค่ไหน
3. ถ้าเป็นสหคลินิก ผู้ดำเนินการ (อายุรแพทย์) ดูแลทั้งสองบริการได้หรือไม่ ต้องมีผู้ดำเนินการแยกสำหรับกายภาพหรือไม่
4. เอกสารครบชุดที่ต้องใช้ และถ้าเลขที่บ้าน/อ.6 ยังไม่ออก รับคำขอไว้ก่อนได้หรือไม่ (ดู `01`)
5. ใช้เวลาตรวจสถานที่และออกใบอนุญาตประมาณกี่วัน ถ้ายื่น 30 พ.ย. เปิด ม.ค. 70 ทันหรือไม่
6. เมื่อย้ายเข้า OPD รพ. ต.ค. 70 ต้องเลิกกิจการคลินิกนี้อย่างไร และย้ายทีมไปอยู่ใต้ใบอนุญาต รพ. ได้ทันทีหรือไม่
7. ป้ายและสื่อโฆษณาคลินิก ยื่นขออนุมัติตาม ม.38 พร้อมคำขอได้หรือไม่

## ทางเลือกตามคำตอบ

| คำตอบ สสจ. | ทำอะไรต่อ |
| --- | --- |
| ยื่นเป็นคลินิกเวชกรรมทั่วไป / สหคลินิก ได้ โดย นพ.รังสรรค์ เป็นผู้ดำเนินการ | เดินตามแผนเดิม ไม่ใช้คำว่า "เฉพาะทาง" ในชื่อและป้าย |
| ต้องเป็นคลินิกเฉพาะทางประสาท | หาแพทย์ที่มีวุฒิบัตรประสาทวิทยาเป็นผู้ดำเนินการ (ถาม นพ.ณัฐวรรธ ได้หรือไม่ เพราะเป็นผู้ดำเนินการ รพ. และคลินิกหมอต้นอยู่แล้ว ต้องดูข้อจำกัดเรื่องดำเนินการหลายแห่ง) หรือเปลี่ยนเป็นคลินิกทั่วไป |
| ต้องแยกเป็น 2 ใบอนุญาต (เวชกรรม + กายภาพ) | ต้องมีผู้ดำเนินการคลินิกกายภาพ (นักกายภาพ) และอาจต้องแยกพื้นที่ในผัง ปรับค่าใช้จ่ายในโมเดล |
