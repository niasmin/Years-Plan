# Single Procedure by Neuro — ประเด็นให้ทนายตรวจ

**ข้อเท็จจริง:** หัตถการทำภายใต้ใบอนุญาตคลินิกหมอต้น (ใบอนุญาตบุคคลของ นพ.ณัฐวรรธ วิฑูรย์) แต่รับเงินจากผู้ป่วยในนามบริษัท ซีเอ็มเอ็นเอช 2012 จำกัด ซึ่งไม่ใช่ผู้รับอนุญาตสถานพยาบาลที่ให้บริการนั้น ผู้ประสานงาน: จุ้บแจง

## คำถามสำหรับทนาย

1. บริษัทที่ไม่ใช่ผู้รับอนุญาตสถานพยาบาล รับเงินค่ารักษาจากผู้ป่วยโดยตรงได้หรือไม่ ผิด พ.ร.บ.สถานพยาบาลหรือไม่
2. ใบเสร็จควรออกในนามใคร ถ้าออกในนามบริษัท ผู้ป่วยใช้เบิกประกัน/สิทธิได้หรือไม่
3. ภาษี: ค่ารักษาพยาบาลของสถานพยาบาลได้รับยกเว้น VAT ถ้าบริษัทเป็นผู้รับเงินแต่ไม่ใช่สถานพยาบาล จะถูกตีความเป็นรายได้ประเภทอื่นที่ต้องเสีย VAT หรือไม่
4. รายได้ที่รับไปแล้วตั้งแต่เริ่มโปรเจ็ค ต้องแก้ไขย้อนหลังอย่างไร (ใบเสร็จ บัญชี ภาษี)
5. ความรับผิดถ้ามีเหตุไม่พึงประสงค์จากหัตถการ: ใครเป็นผู้รับผิด คลินิก แพทย์ หรือบริษัท

## โครงสร้างที่ให้ทนายเลือก

| ทางเลือก | เงินไหลอย่างไร | เอกสารที่ต้องมี |
| --- | --- | --- |
| ก. คลินิกเก็บเงินเอง | ผู้ป่วยจ่ายคลินิก → คลินิกจ่ายบริษัทเป็นค่าบริการ (สถานที่ บุคลากร การตลาด การจัดการ) | สัญญาบริการระหว่างคลินิก–บริษัท · ใบเสร็จคลินิกให้ผู้ป่วย · ใบแจ้งหนี้/ใบกำกับภาษีบริษัทให้คลินิก |
| ข. บริษัทรับแทน (ตัวแทนรับเงิน) | ผู้ป่วยจ่ายบริษัทในฐานะตัวแทนของคลินิก → บริษัทนำส่งคลินิกหักค่าบริการ | สัญญาตัวแทนรับชำระ · ใบเสร็จในนามคลินิก · แยกบัญชีเงินรับแทน |
| ค. ย้ายเข้าใบอนุญาตบริษัท | ทำหัตถการที่คลินิกหน้า รพ. (บริษัทเป็นผู้รับอนุญาต) ตั้งแต่ ม.ค. 70 หรือที่ รพ. ต.ค. 70 | ต้องให้หัตถการอยู่ในขอบเขตใบอนุญาตคลินิกใหม่ (ดู `02`) |

**ข้อเสนอเบื้องต้น:** ระยะสั้นใช้ ก. หรือ ข. ให้ถูกต้องทันที ระยะยาวย้ายไป ค. เมื่อคลินิกในนามบริษัทได้ใบอนุญาต ทั้งนี้ให้ทนายเป็นผู้ตัดสิน

## เอกสารที่ต้องส่งให้ทนาย

- ตัวอย่างใบเสร็จที่ออกให้ผู้ป่วยแล้ว (ปิดชื่อผู้ป่วย)
- ยอดรับเงินรายเดือนตั้งแต่เริ่ม
- ข้อตกลงที่มีอยู่ระหว่างคลินิกกับบริษัท (ถ้ามี)
- รายการหัตถการและราคา
